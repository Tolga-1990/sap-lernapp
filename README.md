# SAP CP Controlling – Lern-App

Lern-App für die Prüfung SAP Competence Pass, Teil CT (Controlling Tasks), bei Digicomp am 20.11.2026.

## Funktionen

- **Quiz** mit 136 Fragen und Musterantworten (Teile A bis F), falsch beantwortete Fragen kommen öfter
- **Karteikarten** mit 52 Transaktionscodes und Befehlen, in beide Richtungen
- **Prüfungssimulation**: 40 zufällige Fragen in 60 Minuten, Ergebnis in Prozent (bestanden ab 60 %, Auszeichnung ab 80 %)
- **Fortschritt** wird nur im eigenen Browser gespeichert (localStorage), nichts wird ins Internet übertragen

## Quelle der Inhalte

Fragen und Antworten stammen aus dem Katalog „Prüfungsfragen mit Musterantworten SAP CP Controlling“, am 16.11.2026 mit dem Skriptum SAP CP CT (Version 1.0 CH, bizConsult 2024) abgeglichen. Die Kapitel stehen in Klammern. Es sind keine echten Prüfungsfragen.

## Bedienung

Die App ist eine einzige Datei `index.html` und läuft über GitHub Pages im Browser, auch auf dem Handy.
